# Quadram Institute Design System

Brand tokens, colour system and the React component library for Quadram Institute
Bioscience — food, microbiome & health research. Consumers link `styles.css` for
all tokens (colour, type, spacing, fonts) and pull components from the compiled
bundle.

## Components

- **DiamondMark** — brand diamond motif for bullets, accents and dividers
- **Button** — primary, impact, secondary and ghost actions with sizes and states
- **IconButton** — compact icon-only action button
- **Card** — content surface with accent-top and inverse variants
- **Badge** — small status / category label
- **Tag** — selectable keyword chip
- **Stat** — headline metric with label and accent
- **Input** — text field with label, helper text and error state
- **Select** — dropdown select from an options list
- **Checkbox** — single boolean choice
- **Switch** — on/off toggle
- **RadioGroup** (aliased **Radio**) — single choice from a set of options
- **Tabs** — underline tab navigation
- **Dialog** — modal confirmation with footer actions
- **Tooltip** — hover hint

## Tokens

Defined under `tokens/` and re-exported through `styles.css`: `fonts.css`,
`colors.css`, `typography.css`, `spacing.css`, `base.css`.
