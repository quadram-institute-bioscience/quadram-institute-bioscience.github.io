LLM APIs

How we'll access AI models

Participants will use OpenRouter as the main platform for accessing Large Language Models. OpenRouter provides a single API that can connect to many providers:

  • OpenAI (ChatGPT)
  • Anthropic (Claude)
  • Google (Gemini)
  • Meta (Llama)
  • Mistral
  • and many others
Using a common API means you can focus on building your project rather than learning multiple provider-specific interfaces.

Example

Your first API call

first_call.py
from openai import OpenAI import os client = OpenAI( base_url="https://openrouter.ai/api/v1", api_key=os.environ["OPENROUTER_API_KEY"] ) response = client.chat.completions.create( model="openai/gpt-4.1-mini", messages=[ { "role": "user", "content": "Explain N50 in simple terms." } ] ) print(response.choices[0].message.content)

A typical workflow is: write a prompt in Python, send it, the LLM generates a response, and you use that response in your application.

With only a few lines of code, you can start building applications that analyse text, summarise documents, explain figures, classify information, and much more.
