What is this about

Python scripts that talk to LLMs

This hackathon focuses on API calls to LLM providers (like Claude) from Python scripts to analyse text, images and scientific documents.

The goal is not to become an AI expert — just to learn enough to build something useful. A good project can be as small as one Python script that solves a real problem.

Find out what the hackathon is about or read the programme and schedule.
