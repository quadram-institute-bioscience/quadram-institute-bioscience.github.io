Build small scientific tools with Python and LLMs

A beginner-friendly virtual hackathon for learning how to call Large Language Models from Python and use them in research, bioinformatics, data analysis, and scientific workflows.

What is this?

A practical hackathon about LLMs as APIs

Large Language Models such as ChatGPT, Claude, Gemini and others can be used from code, not only through chat interfaces.

In this hackathon, you will learn how to send text, documents, images or structured prompts from Python and use the model response inside a small application.

The goal is not to become an AI expert. The goal is to learn enough to build something useful.

The pattern we'll use throughout

example.py
from openai import OpenAI import os client = OpenAI( base_url="https://openrouter.ai/api/v1", api_key=os.environ["OPENROUTER_API_KEY"] ) response = client.chat.completions.create( model="openai/gpt-4.1-mini", messages=[ { "role": "user", "content": "Explain genome assembly N50 in simple terms." } ] ) print(response.choices[0].message.content)

OpenRouter lets us try models from different providers — OpenAI, Anthropic Claude, Google Gemini — through a single common API. You can switch models by changing one string.

This means we can focus on building rather than learning a different SDK for each provider.

No prior AI experience needed. If you can write a Python function and run a script, you have everything required to follow along at the launch session.
Why this is useful

LLMs can transform messy information

Instead of writing complex parsing code, you describe what you want. The model extracts, classifies, summarises, or explains — and returns structured data your code can use.

Structured output

Ask for data, not just paragraphs

A useful trick is to ask the model to reply in JSON. That makes the answer easy to save, search, display, or feed into another function.

You can define the exact fields you want, ask for confidence scores, or request multiple items in an array.

{ "organism": "human gut microbiome", "method": "metagenomics", "main_result": "diet changed microbial composition", "confidence": "medium" }
